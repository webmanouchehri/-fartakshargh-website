


# fartakshargh-website
 
# وبسایت رسمی آموزشگاه فنی و حرفه‌ای فرتاک شرق

نمونه‌کار طراحی و پیاده‌سازی وب‌سایت آموزشی و آموزشگاه فنی و حرفه‌ای

🔗 **مشاهده‌ی سایت:** [fartakshargh.ir](https://fartakshargh.ir/)

## درباره‌ی پروژه
وب‌سایت رسمی آموزشگاه فنی و حرفه‌ای فناوران فرتاک شرق، شامل معرفی دوره‌ها، سیستم ثبت‌نام آنلاین، مقالات و اطلاعات تماس.

## ابزارهای استفاده‌شده
- WordPress
- elementor
- Elementor Pro
- WooCommerce 
- JetEngine
